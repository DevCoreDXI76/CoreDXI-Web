# AX 체크 안전서류 분기 — 영업 지원 채널 전달물 (한 장)

**작성: 코어디엑스아이 · 2026-09-10 · v1 (원본, CoreDXI 홈페이지 2.0 작업지시용)**

> 9/9 전달물(설문 문항 1개)이 실행 큐에 들어가지 않은 것으로 확인되어(9/10, `catalog.ts` v2 그대로·9/6 이후 갱신 없음), 문항 추가와 결과 분기를 **한 묶음**으로 다시 넘깁니다. 이 문서 하나로 설계 문서·Claude Code 작업지시를 바로 쓸 수 있게 만들었습니다. 9/9 전달물의 문항·선택지는 이 문서로 대체합니다.

## 목적 (한 줄)
AX 체크 응답자 중 "안전서류에 월 4시간 이상 쓰는 회사"를 골라내, 결과 화면·메일에 Safety-RAG 사례와 데모 신청을 붙여 **11/30 전 파일럿 후보 1곳**을 찾는다. 리드 수가 아니라 파일럿 1곳이 목표.

## 1. 설문 문항 (Q9로 추가, 라디오 단일 선택)

**질문**
> 귀사는 현장 안전서류(위험성평가표·표준작업계획서·TBM일지 등) 작성에 월 평균 몇 시간을 쓰고 계신가요?

**선택지** (값 키는 개발 편의대로)
1. 거의 없음
2. 월 4시간 미만
3. 월 4~8시간
4. 월 8~16시간
5. 월 16시간 이상
6. 잘 모르겠음 / 담당자마다 다름

## 2. 분기 기준
- **3·4·5번(월 4시간 이상) 선택 시 분기 ON.** 1·2·6번은 분기 없음(기존 결과 그대로).
- 임계값은 오너 결정(2026-09-10, 현장 감각 기준 4시간). 응답 10건쯤 쌓이면 재조정 가능하므로 상수로 빼둘 것.

## 3. 분기 ON일 때 결과 화면·메일에 붙는 블록

**결과 화면 (요약 카드 아래 한 블록)**
> **현장 안전서류, 매번 새로 만들고 계시죠.**
> 코어디엑스아이는 위험성평가표·표준작업계획서·TBM일지 3종을 현장·공종에 맞춰 순서대로 초안 생성하는 시스템을 직접 만들어 운영하고 있습니다. 슬라이드가 아니라 지금 돌아가는 실물입니다.
> [도입 사례 보기(PDF)] [10분 데모 신청]

**메일 (상세본 끝에 같은 블록 + 한 줄 추가)**
> 귀사 서식·공종에 맞춰 구축하는 "안전서류 AI 도입 패키지"(4~6주)도 준비되어 있습니다. 데모 후 안내드립니다.

**링크 대상**
- 도입 사례 PDF: `20260909_제안서_사내_SafetyRAG도입사례_v1` (승인 후 `_draft` 제거본)
- 10분 데모 신청: 기존 AX 체크 상담 신청 폼 재사용 + 숨은 필드 `source=safety_docs` (별도 폼 만들지 않음)

**금지 표현**: "AI로 위험성평가표를 만들어 드립니다" (정부 KRAS가 무료로 제공). 위 문구는 "서류 세트를 귀사 공종·서식에 맞게 + 직접 구축·운영 경험"으로 쓴 것이니 다듬을 때도 이 축은 유지. 화자는 항상 "코어디엑스아이", 개인 직함 없음.
